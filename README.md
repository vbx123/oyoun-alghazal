# عيون الغزال
تشغيل محليًا: `python -m http.server` ثم افتح http://localhost:8000 (fetch لا يعمل من file://).
النشر: ارفع المجلد إلى GitHub ثم Settings → Pages → Branch main. كل المسارات نسبية.
رقم واتساب: `whatsapp` في data/site.json فقط (الرقم الحالي تجريبي).
تصميم جديد: أنشئ designs/<قسم>/design-00X/index.html وأضف كائنه إلى data/designs/<قسم>.json (و featured.json للرئيسية).
قسم جديد: أضف عنصرًا في data/categories.json بـ id وملف data وpage: category.html?c=<id>.
